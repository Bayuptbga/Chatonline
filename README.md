# DriveTok — UI Navbar Bottom

Pembaruan kali ini menambahkan fitur bilah navigasi bawah (bottom navbar) lengkap dengan estetika khas TikTok.

Fitur UI Baru:
- **Bottom Navbar:** Terdapat ikon Beranda, Teman, Kotak Masuk, dan Profil menggunakan format SVG vektor agar tajam di semua ukuran layar.
- **Tombol Plus Khas TikTok:** Tombol tengah didesain menggunakan trik CSS layer pseudo-element (::before & ::after) untuk menciptakan efek tumpukan warna *cyan* dan merah khas TikTok.
- **Penyesuaian Layout:** Posisi teks informasi video dan deretan ikon like/share di sebelah kanan telah digeser sedikit ke atas agar tidak tumpang tindih dengan navbar baru ini.
